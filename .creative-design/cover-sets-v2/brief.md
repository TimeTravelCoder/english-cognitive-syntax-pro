## 一、主题与核心对象

- 主题：《英语认知句法》教材装帧封面套，作为「理论全书」「练习全书」两册书的打印封面，风格需「不俗气」（避开常见渐变光效、玻璃拟态、通用科技蓝紫等俗套），呈现三种彼此差异明显的成熟方向。
- 商品：无实体商品。核心对象为两册书的书名与卷名：
  - 中文主名：英语认知句法
  - 卷名：理论全书 / 练习全书
  - 英文：COGNITIVE ENGLISH SYNTAX · THEORY VOLUME / PRACTICE VOLUME
- 事实来源：书名与卷名为用户既定事实；封底简介为本任务补充文案（agent_generated），仅陈述本教材性质，不虚构出版社、ISBN、条码、作者名或获奖信息。
- 尺寸（物理成品，HTML 按 1in=96px 换算）：
  - 三面展开：理论 432.1×297.1mm（书脊 12mm）、练习 433.1×297.1mm（书脊 13mm）→ 画布 1633×1123 px / 1634×1123 px（练习用 1633+1=1634px，宽差 0.1mm 取整；为保持一致两册统一 1633px，书脊宽度按 mm 精确换算：12mm→45px、13mm→49px，封底与前封各 210mm→794px，理论 794+45+794=1633，练习 792+49+792=1633 不对——按 210mm=793.70px，两册前封/封底各 794px，理论书脊 45px→794+45+794=1633 ✓；练习 794+49+794=1637px → 练习画布 1637×1123px，以书脊折线精确标注）
  - 实际采用：理论三面 1633×1123；练习三面 1637×1123（书脊 49px）
  - A4 前封（两册同）：210×297.1mm → 794×1123 px
- 元素分工：书名、卷名、英文、简介、编号、标签、引导线均为 HTML DOM 可编辑文字/图形；背景由 image_gen 生成无字素材；折线/裁切线在打印版按需以辅助标记呈现（clean artwork 不含）。

## 二、三套设计方向（彼此差异化，均不俗气）

### 套装一「东方文心 · 纸墨」（INK & PAPER）
- 风格指纹：宣纸米白底 + 淡墨晕染山形/水纹 + 竖排书名 + 朱砂小印；留白大于画面，克制的文人书卷气。
- 理论册主色：墨青（深蓝黑墨 #25343c 系）+ 淡赭点缀（#b7a284）；背景为米白纸纹 + 极淡墨青晕染。
- 练习册主色：赭石朱墨（#7a3b2e 系）+ 淡灰点缀；背景同构，晕染偏赭。
- 构图：前封书名竖排两列（「英语认知」「句法」或单列长题），中上部；右下角一枚朱砂小印（方形色块 + 白文，规则图形用 DOM）；左下部留白 + 一行细竖排英文；封底左上竖排简介，右下印章呼应；书脊竖排书名+卷名。
- 禁项：不用毛笔书法字体生成艺术字图片，全部用系统衬线/宋体 DOM 文字；水墨仅作背景晕染，不烘焙书名。

### 套装二「瑞士编辑 · 网格」（SWISS GRID）
- 风格指纹：米白底 + 大留白 + 无衬线细字 + 细红线/强调色块 + 网格刻度 + 编号标签；编辑设计式的理性秩序。
- 理论册主色：钢蓝（#1d3557）+ 猩红点缀（#d62828）；练习册主色：墨绿（#1f4a3d）+ 猩红。
- 构图：前封非对称网格——左上角小标签「THEORY VOLUME · 01」；中部偏左超大号英文标题 COGNITIVE ENGLISH SYNTAX（分两行），其下中文书名横排大字号；右下一个小色块 + 网格刻度；封底网格中简介横排，左下编号；书脊横排小字书名（或竖排）+ 色带。
- 禁项：不用衬线装饰体，全部 Helvetica 类无衬线；不用渐变光效，纯色块与细线。

### 套装三「档案标本 · 纸本」（ARCHIVE SPECIMEN）
- 风格指纹：牛皮纸/档案卡质感 + 衬线细字 + 标签带 + 索引编号 + 图章/胶带痕迹；学术档案的考据感。
- 理论册主色：档案靛（#3d4466）+ 暗红（#9e2b25）；练习册主色：档案苔绿（#4a5d4a）+ 暗红。
- 构图：前封顶部横向标签带（色带 + 白字卷名），中部居中衬线书名（中文横排 + 英文小字），底部索引行「FILE NO. · VOL. THEORY · 2026」；左下角圆形图章（规则图形 DOM）；封底同构，中央简介衬线排版；书脊竖排书名。
- 禁项：不用伪旧做旧过度肌理，纸纹由背景承担；图章/胶带用规则 DOM 图形，不生成位图。
