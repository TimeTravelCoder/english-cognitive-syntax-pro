## 四、 打印与装订指南

1. **首选打印版本**：推荐使用 [`定稿打印版/多元配色修订版/`](定稿打印版/多元配色修订版/)（或最终打印包中的 `01_多元配色修订版/`）。
2. **打印参数设置**：
   - **纸张规格**：标准 **A4**（推荐 80g–100g 微黄护眼道林纸或高白双胶纸；练习册含 2,967 条手写答题线，80g 以上道林纸书写不洇墨）。
   - **双面与缩放**：选择 **双面打印（长边翻转）**，缩放比例务必设置为 **“实际大小”或“100%”**（切勿勾选“适合页面边界”，以免缩小正文字号与手写横线行高）。
3. **装订方式建议**：
   - **理论全书（308 页 / 双面 154 张）**：适合无线胶装或锁线胶装（80g 纸书脊厚度约 15.4–15.5 mm）。
   - **练习全书（364 页 / 双面 182 张）**：强烈推荐 **锁线胶装** 或 **活页打孔/线圈装订**，可实现 180° 完全平摊书写，做题与核对章末解析体验最佳。

## 五、 自动化构建与质量核验管线

如需修改 Markdown 源稿并重新生成全套 HTML 与 PDF，可在安装了 Node.js（含 `marked`、`playwright`）、Python 3（含 `pypdf`）及 Microsoft Edge 的环境中运行一键构建脚本：

```powershell
# 一键完成：HTML 渲染 -> MathJax/Mermaid 矢量化 -> 二级目录页码回填 -> 597/201 书签注入 -> 四套配色编译 -> 终审校验
pwsh ./重建两册.ps1
```

### 核心管线脚本说明

- [`render_theory_html.cjs`](render_theory_html.cjs) / [`render_practice_html.cjs`](render_practice_html.cjs)：解析 Markdown 源稿，执行 MathJax 公式排版、Mermaid 流程图自适应矢量化、练习册 686 个题干与作答区结构化封装、全展开二级目录生成及跨册双向互链注入。
- [`check_pdf.py`](check_pdf.py) & [`sync_final_toc.cjs`](sync_final_toc.cjs)：扫描生成的基准 PDF，精确定位全部 9 篇主标题与 80/69 个二级小节所在页码，写入 `page-map.json` 并回填至目录页。
- [`bookmark_pdfs.py`](bookmark_pdfs.py) & [`恢复全部方案书签.py`](恢复全部方案书签.py)：为基准版及全部 4 套配色方案注入完整的多级 PDF 导航书签（理论 597 个、练习 201 个），并逐一校验页面文本一致性。
- [`核验精简项目.py`](核验精简项目.py) & [`final_pdf_audit.py`](final_pdf_audit.py)：对源稿换行符规范（纯 CRLF）、题号唯一性、作答区配对、书签跳转有效性及未渲染符号残留进行自动化零缺陷断言。
